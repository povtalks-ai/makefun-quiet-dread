## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

`main.py` (Python 3, standard library only) builds the comment from
three beats — the approval, the reassuring fact, and the dread, with the
sting in the last clause — validates it against the gate (1 to 140
characters, one line, not only whitespace), writes it to
`/output/entry.txt`, then reads it back to prove the file holds exactly
the validated line. Three runs produce byte-identical output.
